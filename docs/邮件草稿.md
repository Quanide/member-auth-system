**关于邮件功能，有一点需先向两位说明**：
邮箱验证、忘记密码、变更邮箱这三项的完整流程（签章连结、一次性 token、
时效控制、重寄限流）皆已实作完成，并有对应的自动化测试覆盖；
但示范站目前**尚未接上对外的 SMTP 服务**，邮件是以写入日志的方式记录，
因此在线上点击「重寄验证信」或「忘记密码」时，画面会显示寄送成功，
实际上不会真的收到信件。

这是考量到示范用网域尚未完成寄件网域验证（SPF / DKIM），
贸然接上发信服务反而容易被判为垃圾邮件。
若贵公司希望实际验收这段流程，我可以在收到通知后接上 SMTP，
或改以录影方式呈现完整的收信与验证过程，再请告知您方便的方式。

**關於郵件功能，有一點需先向兩位說明**：
信箱驗證、忘記密碼、變更信箱這三項的完整流程（簽章連結、一次性 token、
時效控制、重寄限流）皆已實作完成，並有對應的自動化測試覆蓋；
但示範站目前**尚未接上對外的 SMTP 服務**，郵件是以寫入日誌的方式記錄，
因此在線上點擊「重寄驗證信」或「忘記密碼」時，畫面會顯示寄送成功，
實際上不會真的收到信件。

這是考量到示範用網域尚未完成寄件網域驗證（SPF / DKIM），
貿然接上發信服務反而容易被判為垃圾郵件。
若貴公司希望實際驗收這段流程，我可以在收到通知後接上 SMTP，
或改以錄影方式呈現完整的收信與驗證過程，再請告知您方便的方式。
